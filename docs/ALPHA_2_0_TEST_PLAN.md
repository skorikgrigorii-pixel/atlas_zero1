# План тестирования Alpha 2.0

1. Запустить start_os.bat.
2. Нажать «Запустить конвейер».
3. Проверить Live Run Console: прогресс должен идти постепенно.
4. Открыть «Граф конвейера»: все этапы должны перейти в Completed или Failed.
5. Открыть «Менеджер задач»: задачи должны иметь ID, статус, попытки, время.
6. Открыть «Визуальный анализ» и CV Runtime exports.
7. Открыть Экспорт и проверить pipeline_graph.html, cv_runtime_report.html, pipeline_run_report.html.
